# ShailKing E-Commerce Web Application

A full-featured online shopping web application built using Enterprise Java technologies.

## 🛠️ Tech Stack
- **Backend:** Java, JSP, Servlets
- **Database:** Oracle 10g
- **Application Server:** WebLogic Server
- **Frontend:** HTML5, CSS3, JavaScript

## ✨ Key Features
- User Authentication (Login / Register)
- Product Catalog & Search
- Shopping Cart System
- Order Placement & Management System
